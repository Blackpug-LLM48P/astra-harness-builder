# Coding Task Example

## Objective

Implement a bounded change in an existing repository.

## Boundaries

- Read repository instructions before editing.
- Preserve unrelated user changes.
- Modify only files necessary for the requested behavior.
- Do not publish, deploy, or open a pull request unless requested.

## Acceptance criteria

- Requested behavior implemented.
- Relevant tests pass.
- Static or type checks pass when available.
- Remaining risks and unverified assumptions reported.
