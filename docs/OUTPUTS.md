# Output Reference

## Full operational instruction

The most complete output. Use it for a substantial one-off task that needs explicit scope, delegation, permissions, verification, and reporting rules.

## Compact task prompt

A shorter task-specific version for environments where standing rules already define safe behavior. Review it carefully; compactness necessarily removes detail.

## `AGENTS.md` snippet

A reusable standing-instruction fragment. It intentionally excludes the one-off task and its acceptance criteria. Merge it manually and resolve conflicts with existing repository instructions.

## Configuration

A machine-readable record of the selected controls. Keep it with test evidence when reproducibility matters.

## Usage notes

A human-readable explanation of the bundle and its limits.

## Export discipline

Treat every generated file as a draft. Review target names, external-action gates, retry limits, delegation ceilings, and completion evidence before use.
